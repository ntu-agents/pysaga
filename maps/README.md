# Maps

Maps contributed by the community, one folder per map: `<Name>/<Name>.json` in the
saga-map format ([docs/maps/saga-map.md](../docs/maps/saga-map.md)). Any of them trains
with `SagaEnv(map_name="maps/<Name>/<Name>.json")`.

Before sending one, check that the game reads it: an environment made from it resets
without an error, and the replay page draws it.
