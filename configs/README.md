# Training configurations

EPyMARL configurations and scripts that reproduce a result: one folder each, with a
README saying what it trains, the command, the pysaga version (`PUBLISHED.txt`), and
what came out: win rates, learning curves, a baseline table. The policies a configuration
trained go in `policies/`, their README naming the configuration.
