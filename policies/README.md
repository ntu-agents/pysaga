# Policies

Trained policy files (`python -m pysaga.export`), one folder each, with a README naming
the configuration in `configs/` that trained them and the pysaga version
(`PUBLISHED.txt`). A policy file loads only into the observation layout it was trained
on. Play one in the game with the lobby's Add bot, or measure it against the game's bots
with `python -m pysaga.balance`.
